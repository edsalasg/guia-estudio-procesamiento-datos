# Guía de estudio · Análisis y Procesamiento de Datos

Doctorado en Ciencias Administrativas · DCEA · Universidad de Sonora · 2026-2

Guía interactiva de las sesiones 1 a 8 (13-08-2026 al 01-10-2026): vista de estudio por sesión, salidas reales de SPSS interpretadas, capturas de clase, gráficas, intérprete de salidas con 71 reglas de decisión, autoevaluación y 15 videos de repaso narrados (uno general y, por sesión 2 a 8, uno de fórmulas y gráficas y otro de interpretación).

**Ver en línea:** abrir `index.html` desde GitHub Pages.
